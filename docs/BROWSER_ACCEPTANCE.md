# 浏览器验收门槛

## 当前结论（2026-10-20 UTC）

**真实浏览器验收尚未通过，不得把单元测试、HTTP 回归或本文件视为 UI 验收通过。**

本轮使用全新的临时 SQLite、只监听 loopback 的后端，在同一个 shell 中确认首页返回 HTTP 200。随后通过受支持的 dot 云端浏览器接口打开 `http://127.0.0.1:3019`，浏览器返回 `net::ERR_CONNECTION_REFUSED`。这说明当前执行器服务无法被该浏览器访问，不代表应用页面测试失败。未创建隧道、代理或外部部署，也未绕过此前 Chromium 启动与执行器权限拒绝。

没有取得本轮页面截图或真实浏览器交互通过证据。`tests/browser_smoke.cjs` 目前只通过 JavaScript 语法检查；新加入的浏览器断言仍需在支持同机浏览器的环境执行。

## 可复现入口

在可运行 Chromium 的开发或 CI 环境安装 Playwright（见 tests/README.md），然后运行：

```sh
bash tests/browser_run.sh
```

该入口构建前后端，创建一次性数据库，在同一个 shell 启动并清理自己的服务，设置合成测试标记。固定测试端口 3019 必须空闲；端口占用时应停止而不是连接既有实例。不要替换为真实数据库。截图默认保存在 `artifacts/browser/`，只包含合成测试记录。

脚本拒绝非 loopback URL，且要求 `NOLYA_SYNTHETIC_DB=1`。这只是防误操作措施，不能证明手工提供的数据库确为测试库，优先使用上述自动入口。

## 静态复核备注

Friends 和 Guess 路由已按 pathname 设置 React key，避免更换邀请 token 后沿用上一链接组件状态。此项属于源码核查，不是浏览器证据。身份变化的异步响应与页面本地状态仍需集成测试；不能仅凭路由 key 宣称已解决全部跨身份问题。
