# Nolya 0.4 全页面设计覆盖

本轮依据用户提供的 NolyaV1.1 原始包逐页实施，而不是把同一张首页照片铺到所有页面。Page01 使用最新 v2，Page02–10 使用对应 China Entry v1.1，Page11–18 使用各自 v1.0。所有控件、问题、答案、计数与结果仍由真实应用状态渲染。

## 没有独立页面原稿的路线

`/account`、`/recover`、`/help`、`/self/history` 和 404 在原包中没有专门的 PageXX mockup。它们沿用冻结的 Warm Editorial × Playful Social 设计系统，并采用原包 `logo/logo.png` 和 `logo/logo_text.png` 品牌素材。不会为了凑图片数量插入与安全、隐私说明无关的人像，也不会把这些扩展页面称为逐像素还原。

## 素材与动态内容

- 所有照片及品牌 PNG/JPG 直接来自原始包，没有图库替换或 AI 代画。原始字节及来源记录在 `DESIGN_ASSET_MANIFEST.json`。
- 部分原包只有合成 mockup，没有独立人物照片。使用原 PNG 配合 CSS 裁切，仅露出照片区域；控件、正文、结果和计数禁止来自截图。每处裁切坐标及边界见对应实现说明。
- 首页沿用已验证的最新 v2 裁切，而不是旧人物；03 的两张已入库但未引用照片本轮真正接入结果页。
- 镜像比较、每日统计和历史图示使用实际数据绘制。这些是动态信息，不应替换为固定截图中的示例数值。
- 分享海报继续本地生成，二维码与文案对应当前链接/明确选择的结果预览。平台按钮是导出、复制与系统分享辅助，不是已接入平台 SDK 的自动发布。

## 不可因视觉还原改变的规则

完整镜像仍需三个独立响应；少量样本仍不显示百分比；未提交猜测仍不能看到答案；反向邀请仍仅供指定原邀请人；生成邀请不能标成已发送。原稿的示例姓名、统计、连续天数与回复不能当成真实数据展示。

## 验收边界

本轮截图和回归必须绑定新的最终提交，不能把 0.3 的通过记录当成本轮证据。覆盖所有上表状态的桌面/手机截图、原图加载、移动不溢出、实际保存与复制动作、真实二维码解码、完整 HTTP/身份/撤回/重启回归。实际第三方 App 发布、完整设备矩阵、生产 HTTPS 部署仍需独立验收。
