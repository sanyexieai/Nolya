覆盖：

1. 预览/取消不改变产品记录或会话；token 仅存摘要
2. 错密码、未知字段、无效输入不改变身份

4. 确认文字、过期、重新预览使旧 token 失效
5. token 绑定原源会话及目标身份，不可跨会话盗用
6. 退出使该会话预览失效，不移动记录
7. 成功后源身份所有会话及其预览均失效
8. 删除后重建同名目标不能复用旧批准
9. 完整关系图迁移：所有权、源快照、时间、链接、预约、反馈、备注、Reverse 目标、旧会话、导出和删除
10–11. 同日 Pulse（相同选择也阻止）、重复已完成 Friends
12–14. 重复预约、回答/预约重叠、撤回重建后的跨链接同 cohort 重复
15–16. 双向跨身份 Friends 回答/预约禁止变成自我评价
17–18. 同轮 Guess 重复，以及重发链接后同来源重复

22. 幂等作用域/key 冲突保留双方重试历史
23–26. 源/目标产品数据和昵称变化使预览失效
27–28. 第三方新增 Friends 回答或 Guess 参与使预览失效

第 9 项还检查：源与目标的旧 Self 创建请求仍重放同一 assessment，不新增结果；受影响 peer 揭晓缓存体被清空、相同旧 key 返回 `idempotency_stale`、改内容返回 `idempotency_conflict`；无关缓存保持；删除合并账户不会删除他人自己的 Self。

同一测试套件也验证指定固定端口可以重复运行、占用端口在任何 HTTP 连接前被拒绝。没有把 fixture 的直改 SQL 或合成身份当成真实用户数据。

## 本轮发现并修复

- 缓存直接清除会失去历史重试保护，可能再次创建 Self。迁移保留键/摘要及不可变 Self 结果，其他相关响应体失效化，保持冲突保护
- 已完成的外部 Friends 邀请撤回后仍保留回答和预约；最初指纹未覆盖该邀请行。指纹现包含双方参与的外部邀请，新增用例确认旧预览返回 `merge_preview_stale`
- 确认 POST 响应丢失不代表服务器未提交。UI 不再直接保证“尚未合并”，而是读取 `/session` 核对；读取失败时只允许刷新状态，不能盲目再次合并
- 密码验证异步等待期间身份/会话可能被注销或合并。登录、注册与合并预览在进入写事务后重新验证活跃源会话；预览/登录重新检查已验证目标凭据仍对应原身份

## 明确边界

这是“无冲突合并”，不是完整身份冲突解决。两边都答了同一天 Pulse 是常见阻塞，必须保留两个空间。没有覆盖投票、丢弃冲突或后台静默部分迁移。生产身份提供商、密码找回、自动 retention、真实跨设备公网试用、部署和生产安全验证仍未完成。
