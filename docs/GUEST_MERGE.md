# 访客记录合入已有账户

日期：2026-10-20 · 本地后续里程碑 · 实现完成；真实浏览器验收仍阻塞

## 用户路径

1. 有记录的访客登录已有账户时，普通登录仍返回 `guest_merge_required`，当前访客保持登录
2. 使用输入的用户名和密码请求合并预览。验证成功后只显示目标账户昵称、用户名、访客记录数量和阻塞原因，不切换身份、不移动或删除任何产品记录
3. 用户确认具体目标、记录数量和链接昵称变化后，以一次性预览凭据提交合并。未提交确认时，用户取消、离页、刷新或预览到期都不会触发合并。提交确认后，离页或网络中断不代表服务器事务取消，必须重新读取会话/账户核对结果
4. 成功才切换到目标账户并轮换 Cookie/CSRF。原访客的所有会话失效；目标账户其他会话仍有效

预览只创建最长五分钟的临时授权记录，不保存密码，数据库仅保存授权 token 的摘要。该记录绑定当前访客会话、两个身份及预览时的产品数据指纹。预览不是登录成功，也不是可复用的账户访问凭据。

## 不丢失数据的冲突边界

这一里程碑支持**无冲突的完整迁移**，不宣称解决所有既有身份重叠。以下任一条件使预览不可确认，两个空间原样保留：

- 两个身份在同一日期已有 Pulse 答案，包括选择相同的情况；不会覆盖已有答案或把同一个人重复计票
- 两个身份参与或预约同一 Friends assessment；不会把两个回答静默合并、丢弃或计为两人
- 两个身份猜过同一个 Guess 轮次，或对同一邀请人的同一保存答案已有猜测；不会选择较有利的结果改变理解度
- 任一身份回答/预约了另一身份的 Friends，猜过另一身份的 Guess，或两个身份之间存在定向 Reverse；合并不能制造自己评自己/猜自己的证据
- 两个身份都拥有针对同一 parent 的 Reverse 回合；不能合并后保留重复方向性来源
- 两个身份有同一作用域和 key 的幂等请求记录；不能静默丢弃任一身份的重试保护

预览列出每类阻塞的数量和说明，不返回他人的原始答案。被阻塞时可以继续访客体验、导出备份或注册独立账户；本版不提供“忽略冲突继续”。这替换首版 API 中尚未实现的“保留已有答案、丢弃/排除冲突”设想。

## 事务与隐私

- 保留全部 Self assessment 及原 Friends cohort 绑定；最新结果仍按原创建时间确定
- 无重叠 Pulse、Friends、Guess 和相关备注、反馈、分析事件全部迁移；ID、快照、来源、创建时间、撤回和过期状态不改变
- 外部朋友的邀请/猜测数据不归本账户所有；只更新本人的参与身份及指向本人的 Reverse 目标
- 目标账户用户名、密码、昵称、语言和地区不被访客设置覆盖。已有分享链接会显示目标昵称，预览必须明确提醒
- 迁移并保留双方的幂等键和内容摘要。不可变的 Self 创建响应可继续重放原结果；其他涉及双方和受影响链接的响应体清空并标记失效，旧请求返回 `409 idempotency_stale`（改内容仍返回 `idempotency_conflict`），避免重复提交或旧揭晓重放；其他身份的无关请求保持
- 合并确认再次验证活跃源会话、目标账户、指纹和冲突；源或目标新增/修改记录后须重新验证密码和预览，不能以旧确认覆盖新数据
- 转移所有外键后删除空访客身份，撤销其全部会话和预览凭据；任何 SQL 失败整个事务回滚
- 导出继续使用字段白名单，不包含预览凭据或密码。合并后删除账户应删除其完整合并记录并清理相关外部缓存
