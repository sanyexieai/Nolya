# 社交分享能力与边界

本轮视觉以用户提供的原始 Page04、Page09 与全局设计规范为依据，来源见 DESIGN_ALIGNMENT.md。本实现提供真实可导出 PNG 海报、离线二维码、可编辑文案、复制实际邀请链接，以及浏览器支持时的系统分享，不伪装官方 SDK 直发。

## 用户流程

- 微信好友：复制专属邀请链接粘贴到聊天，或保存海报发送图片。创建页/管理页并不是邀请链接，不建议直接转发当前页。
- 朋友圈：保存1080×1080方图、复制文案，进入朋友圈选择图片，自行确认可见范围。
- 抖音：保存1080×1920竖图，在应用内选择图片并手动编辑文案。平台可能限制二维码或外链。
- 小红书：保存1080×1440图片，手动选择图片、粘贴并编辑文案。平台可能限制二维码或外链。
- 系统分享：由系统选择可用应用，网页不能指定微信/抖音/小红书。用户取消不会自动下载或复制；成功回调只表示交给系统，不表示已发布。

海报在浏览器本地生成，不上传第三方渲染服务。默认不包含账户ID、恢复码、原始答案、谜底、朋友个人回答。反向邀请始终注明定向参与，请私发。结果分享默认收起，需要主动预览，只使用概括；应用首页链接不公开个人结果。用户仍应核对编辑后的文案和可见范围。普通邀请可以被转发，获得链接的人可能参与。

链接和二维码使用服务真实来源地址。本机/局域网地址不保证其他设备可访问；公网使用仍需要操作者部署可达HTTPS环境。本轮没有进行部署。

## 预览与移动界面

平台入口先显示三步短指引；完整平台限制和隐私说明保留在可展开的“平台说明与分享隐私”中，不把取消、未接入SDK等事实隐藏成成功提示。本机/局域网链接、定向邀请及结果应用链接不含个人结果的提醒保持直接可见。保存海报和复制链接放在预览下方，结果分享仍需主动展开。

3:4和9:16海报使用双视角色卡构图，方形使用紧凑排版；所有格式保留相同真实二维码，文案最多3行并明确预览截断，复制文案保留全文。海报不追加昵称、个人回答或谜底。

## 官方能力核验（2026-10-21）

- [W3C Web Share](https://www.w3.org/TR/web-share/) 要求安全上下文及用户激活。图片预先生成，点击立即调用 navigator.share，并用 canShare 检查文件支持。resolve 不证明发送或发布成功。
- [抖音官方 H5 分享](https://open.douyin.com/platform/resource/docs/develop/share/H5/) 需要申请 h5.share/open.get.ticket、client_key 及服务端 token、ticket、签名。当前未接入，不通过猜测 scheme 代替。
- [小红书分享开放平台](https://agora.xiaohongshu.com/) 当前显示暂停接入；[JS SDK](https://agora.xiaohongshu.com/doc/js) 需要审核后的 appKey/appSecret、服务端签名和服务器媒体URL，不支持本地 File，且不再自动填充标题/文案/话题。本轮不承诺可以立即申请接入。
- 微信 JS-SDK 原始官方页面本次不可读；[腾讯官方接入文档](https://docs.cloudbase.net/integration/wechat-pay-jsapi-h5) Q7说明分享等 JSSDK 能力需要 wx.config 鉴权。本轮未配置 SDK 或声称已完成官方接口实测。

没有创建OAuth授权、申请平台账号/密钥、传输凭据，或向真实社交账号发布。未来SDK接入必须另行完成平台准入、安全域名与服务端签名配置；客户端不得保存密钥。

## 测试范围

单元和组件测试验证链接校验、Unicode换行、定向邀请语义、复制失败、系统分享取消/失败及预览重置。托管 Chromium 验证实际PNG下载尺寸、独立二维码解码、文案编辑和移动布局。系统分享API替身不等同于真机平台发送验证。最终结果记录于 RELEASE_VERIFICATION.md，未通过的门槛不得写作完成。
