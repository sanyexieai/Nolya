# 用户界面文案审计（2026-10-22）

## 本轮原则

按用户最新要求，界面直接说明功能、操作、保存状态和结果，不用“今天记一笔”“收好故事”“慢慢拼出更多的你”等装饰性叙述。保留必要的隐私、安全、样本量、结果不确定性与平台能力说明；第一人称“我的结果”指当前用户，不是系统的自述。

## 覆盖范围

- 首页、全局导航、页脚、加载与错误页。
- 自我答题、结果、朋友邀请与镜像对比。
- 普通猜选、定向反向邀请、已提交和揭晓状态。
- 今日答题、结果、记录列表、空状态与我的空间。
- 登录、注册、账户设置、恢复码、帮助与镜像历史。
- 分享面板、默认分享文案、导出海报标题及图片说明。

## 不变的业务边界

问卷题目、实质选项、计分、三位独立回应的镜像门槛、实际样本统计以及访问控制均不因文案调整而改变。前端回归测试校验问题目录 SHA-256，避免把文案清理扩大成题目或选项改写。

实际结果仍来自保存的答案。海报使用原设计品牌图片，明确不是用户照片；私密答案、朋友个人回答和谜底不会因配图加入分享内容。登录背景仅为视觉内容，不改变认证、账户合并、恢复或删除流程。

## 验证方式

静态回归检查已移除的代表性叙述不再进入界面源码。组件测试及真实浏览器测试继续通过实际按钮和可见状态验证流程，文字选择器随新文案更新，不以隐藏或跳过断言代替验证。导出图片需独立检查照片像素、尺寸、二维码和加载失败恢复。完整截图及测试结果以本提交的 GitHub Actions 终态为准，不借用旧提交的通过结果。
