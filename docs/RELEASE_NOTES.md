- TypeScript/Vite 生产构建通过
- 独立真实 HTTP 主流程、三人并发/重复防护、50票阈值及实际重启持久化通过

浏览器运行被当前环境阻塞：Chromium socket 权限错误，升级执行的沙箱挂载失败，云端替代路线亦无法完成预览启动。没有绕过限制，也没有以原型截图冒充实际运行结果。

因此，真实点击、移动视口、可访问性和中断/重复操作尚未通过浏览器验收。需在可用环境补跑浏览器测试；生产构建通过不代表这些体验已经验证。

## 明确限制

- 有数据的游客登录既有账户会安全返回409并保留原数据；完整合并未实现
- 仅中文；没有真实邮箱/微信登录、验证码发送或密码找回
- 账户导出供保存查看，尚不支持自动导入恢复
- 过期访问会拒绝；自动清理过期数据和备份保留策略未实现
- 不同浏览器身份无法证明不同真人；本地链接不能直接邀请远方朋友
- 正式部署、HTTPS/备份/监控、生产反滥用、隐私条款及素材商用权利需要另行完成

## 运行

按项目 [README](../README.md) 配置并运行 `./scripts/run.sh`，默认访问 `http://127.0.0.1:3000`。建议使用测试账户与独立测试数据库。交付范围与后续门槛见 [DELIVERY_PLAN](DELIVERY_PLAN.md)。

补充验证：前端11项API客户端测试通过；Rust release优化构建通过。浏览器渲染及点击仍未验收，静态HTTP路由检查不能代替浏览器测试。

最终发布前复测（2026-10-19 04:18 UTC）：优化版 Rust 二进制真实 HTTP 主链路、6个SPA页面及其构建JS/CSS服务、同SQLite停止重启后续验全部通过。修复了SPA深链404并新增回归。未进行浏览器实际渲染。

附带Linux x86_64本地启动包，要求glibc 2.34+；无数据库、用户凭据、Rust/Node工具链。并非公网部署或GitHub Release。
