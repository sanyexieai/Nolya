本轮目标：从本地原型推进为具备完整使用流程、账户自助维护、安全数据处理与可部署交付物的单机 Web 产品。后端 Rust + Axum，SQLite 持久化；中文、手机优先。

## 定义和边界

“功能实现”“自动化回归通过”“真实浏览器验收”“公网部署”是四个独立状态。只有前三者满足才可以称该范围的发布候选已完整验收；公网部署另外需要明确环境与授权。当前托管 Chromium 的 25 项脚本检查已通过，但其覆盖不等于全部浏览器、可访问性或生产验收，不将本轮称为已全面验收的生产产品。

## 仍需真实环境完成的发布门槛

1. 已通过 Chromium 1440×1000、390×844 的指定场景、25 项检查及 8 张截图，页面异常为空。仍需完整键盘/读屏、Safari、跨设备 HTTPS 邀请、未覆盖的失败/中断场景及人工视觉审阅。320/430px 只有几何回归，没有实际浏览器视口证据；不得合并声称四种宽度均完成浏览器验收。
2. 拟上线环境的 HTTPS、域名、边缘限流、代理超时、备份调度/异地存储、恢复演练和告警。当前没有实际部署，也未声称模板已经在目标环境验证。
3. 运营主体、隐私联系渠道、服务协议与适用法规审定。内置隐私/帮助为事实性产品说明，不是法律审查意见。无真实邮件或微信集成。
4. 本地用户名是账户标识，不是验证邮箱或独立真人身份。恢复依赖用户预先保存的恢复码；若密码和恢复码同时丢失，没有管理员绕过或虚构找回渠道。
5. 单进程 SQLite 的适用范围是小规模单机服务。全局安全限流不是完备的真实人群防刷，不能保证大规模、多实例或高可用。
6. 访客合并遇到冲突保留双方数据并停止，尚无冲突择优覆盖工具。界面须说明解决路径，不偷偷丢弃任何一方。
7. 首轮托管 verify 已包含成功的 Docker 构建。Compose、Caddy/TLS、卷权限、systemd 和真实部署演练仍待完成；镜像构建通过不等于容器运行或生产上线。
