# 首页随机文案（2026-10-22）

每次首页组件重新进入或页面重新加载时，以等概率抽取一组完整的眉题、三行标题和说明；当前访问中保持稳定，会话刷新或普通重渲染不会切换。离开首页再返回会重新抽取，允许连续抽中同一组，不保证轮换。选择只存在当前组件内存，不设置 Cookie、本地存储或追踪标识。

两个功能按钮固定为“开始回答 8 道题”和“查看朋友反馈”。问卷、答案、分数、导航、隐私提示与朋友反馈门槛不随机化；保留原设计图片和已有桌面/手机字号。

## 五组文案

### everyday-choices

自我选择 · 朋友反馈 · 每日记录

回答生活情境题， / 了解自己的选择， / 对照朋友的看法。

回答 8 道生活情境题，查看你的选择结果。邀请朋友各回答 3 道题，对照自己的选择与朋友的看法。

### friends-perspective

朋友眼中的你

朋友怎么看你？ / 邀请他们回答， / 查看他们的反馈。

先回答 8 道题，查看自己的选择结果。再邀请朋友各回答 3 道题，了解他们的看法。

### compare-views

自己的选择 · 朋友的看法

你的选择， / 朋友的看法， / 有哪些不同？

通过 8 道生活情境题记录自己的选择，再用朋友各 3 道题的反馈，对照相同与不同之处。

### choice-history

生活选择 · 每日记录

回答生活问题， / 查看选择记录， / 回顾不同答案。

从 8 道生活情境题开始，也可以回答每日问题。邀请朋友各回答 3 道题，查看他们的反馈。

### start-with-yourself

从你的答案开始

面对生活情境， / 你会怎么选？ / 答完查看结果。

回答 8 道题，查看基于本次答案的结果。朋友各回答 3 道题后，你还可以对照他们的看法。

## 验证边界

前端测试验证五组文案、等分区间和边界、自然重复、StrictMode、真实 SessionProvider 重渲染、路由离开/返回、前进/后退及重新挂载。浏览器检查使用独立合成访客与测试端 Math.random 控制，不增加生产查询参数或覆盖 crypto。

真实浏览器对每组分别检查 320、390、430 与 1440px：完整文案、文字容器边界、图文分隔、标题/正文/按钮不重叠、两个按钮可达且不被固定导航遮挡，并输出 20 张首页局部截图及 home-copy-variants.json。原有全站检查继续执行。

本文件描述实现与验收要求，不把本地单元测试等同于浏览器视觉通过。最终结果以同一源码提交的 GitHub Actions 终态和对应截图证据为准。
